# ethang.dev

A fully static site, generated by a Rust binary and deployed to Cloudflare with the
`cf` CLI. The build reads `content/` and writes plain HTML, CSS, and assets to `dist/`.

## Constraints

- **No JavaScript or TypeScript, anywhere.** Not in the source tree, not in the build
  output. The site is HTML, CSS, and assets only. `tests/no_javascript.rs` enforces this
  over both the repository and `dist/`, so a build step that reaches for a JS tool fails
  the test suite first.
- **`cargo` is the only package manager.** There is no `package.json`, no `node_modules`,
  no bundler, no Tailwind. Do not run `npm`, `npx`, `pnpm`, or `cf init` - `cf init`
  generates `cloudflare.config.ts` and `vite.config.ts`, which would break the rule above.
- **The output is a static site**, deployed as an assets-only worker. No Cloudflare Pages,
  no server-side rendering.

## Usage

```sh
cargo run -- build            # writes dist/
cargo run -- build --out tmp  # writes elsewhere
cargo test                    # includes the no-JavaScript guard
```

## Toolchain note

`rust-toolchain.toml` pins the GNU toolchain. This machine has no MSVC linker
(`link.exe`), so the default `x86_64-pc-windows-msvc` toolchain cannot link; the GNU
toolchain brings its own linker and needs no Visual Studio install.

## Layout

| Path | Purpose |
| --- | --- |
| `src/main.rs` | CLI: `build --out <dir>` |
| `src/lib.rs` | Module tree |
| `src/html.rs` | Escaping and the element builder |
| `src/content.rs` | Frontmatter, post loading, pagination |
| `src/markdown.rs` | Markdown plus the MDX component expander |
| `src/highlight.rs` | Build-time syntax highlighting |
| `src/math.rs` | LaTeX to MathML |
| `src/images.rs` | Build-time image resizing and srcsets |
| `src/pages/` | One module per page |
| `static/` | Fonts, favicon, committed diagram SVGs |
| `content/` | Markdown posts and pages |
| `tests/` | Guard tests |
